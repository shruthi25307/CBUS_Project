# CBUS_Project

## Description

CBUS is a responsive college transportation portal designed to simplify access to bus-related information for students and staff. The platform serves as a centralized hub where users can conveniently access route details, schedules, transport announcements, driver and staff contact information, and bus tracking features through a clean and user-friendly interface.

The portal aims to improve communication between commuters and the college transportation system by providing essential travel information in one place. Users can stay informed about route changes, service updates, important announcements, and other transport-related notifications without needing to rely on multiple sources.

Built using HTML, CSS, and JavaScript, CBUS focuses on delivering a modern, responsive, and accessible user experience across desktop, tablet, and mobile devices. The project incorporates interactive elements, smooth navigation, theme customization, and dynamic content updates to enhance usability and engagement.

As a front-end focused academic project, CBUS demonstrates the practical application of web development concepts including responsive design, structured layouts, user interface design, JavaScript interactivity, and organized content presentation. The project currently utilizes fictional data and placeholder information for demonstration purposes and does not include backend integration or real-time data connectivity.

CBUS was developed with the vision of creating a simple yet effective transportation information system that makes daily commuting more convenient for students and staff while showcasing modern front-end development practices.

This project is my first complete web development project and serves as a practical application of front-end development concepts, including responsive design, user interface development, and JavaScript-based interactivity.

## ✨ Features

* Bus route information and route listings
* Bus tracking interface
* Transport schedules and travel details
* Driver and staff contact information
* Announcements and service updates
* Real-time date and time display
* Responsive design for all devices
* Interactive user interface
* Theme switching functionality
* Smooth animations and visual enhancements
* User-friendly navigation and layout

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Font Awesome
